# Проверка непереведённого текста

Проверка ищет английский текст на русском экране. Нужна, чтобы при синхронизации с оригиналом новые английские строки не прошли незамеченными.

## Когда включается

- В dev-сервере (`pnpm dev` в `apps/web`) при русском интерфейсе — всегда.
- В любой сборке, включая приложение для Mac:
  - параметр `?i18n-check=1` в адресе;
  - или в консоли: `localStorage.setItem('thb-i18n-check', '1')` и перезагрузка.
- `?i18n-check=0` выключает проверку.

Когда проверка выключена, её код не загружается.

## Что делает

- Следит за страницей и смотрит текст, а также атрибуты `title`, `placeholder`, `aria-label`, `alt`.
- Английским считает текст, где есть английское слово. Имена людей и племён, «The Human Box», названия клавиш, единицы и технические названия не считаются. Список исключений: `apps/web/src/i18n/dev/allowlist.ts`.
- Слова языков племён (окно «Язык») пропускаются. Любой элемент можно исключить атрибутом `data-i18n-ignore`.
- Отмечает id из симуляции, для которых у `simLabel()` нет русского названия.
- Текст, который пишет сама симуляция (мысли, события, новости, летопись), до этапа 0.4 остаётся английским. Он идёт отдельной группой `sim-text` и по умолчанию скрыт. Где он показывается: `apps/web/src/i18n/dev/sim-text.ts`.

## Как пользоваться

В консоли браузера (в приложении для Mac: Вид → Инструменты разработчика):

- `__i18nReport()` — таблица находок: текст, сколько раз встретился, где, когда впервые;
- `__i18nReport({ sim: true })` — то же вместе с текстами симуляции;
- `__i18nReport.json()` — то же в JSON, удобно вставить в issue;
- `⌥⇧I` (Alt+Shift+I) или `__i18n.highlight()` — обвести найденное на экране;
- `⌥⇧S` или `__i18n.showSim()` — обводить и тексты симуляции.

## Автоматический обход

`scripts/i18n/scan-ui.mjs` открывает игру в Chromium, включает скорость 10×, по очереди открывает окна, карточки людей и племён, разговоры и семейное древо, затем сохраняет отчёт и скриншот с подсветкой.

```sh
# один раз: Playwright вне проекта
mkdir -p /tmp/pw && (cd /tmp/pw && npm i playwright && npx playwright install chromium)

cd apps/web && pnpm dev --port 5199 &
PLAYWRIGHT_DIR=/tmp/pw node scripts/i18n/scan-ui.mjs --url http://localhost:5199/ --minutes 3 --out /tmp/i18n-scan
```

Отчёт: `/tmp/i18n-scan/i18n-report.json`, скриншот: `/tmp/i18n-scan/highlight.png`.

## Что делать с находкой

- Строка интерфейса → ключ в `apps/web/src/i18n/catalog/*.ts` по [глоссарию](GLOSSARY.ru.md).
- Id из симуляции → запись в таблице `apps/web/src/i18n/sim/*.ts`.
- Латиница, которая должна остаться латиницей → `allowlist.ts` или `data-i18n-ignore`.
