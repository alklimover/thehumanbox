# Глоссарий и стиль перевода

Один словарь для всех, кто переводит интерфейс The Human Box RU. Если термина здесь нет, его нужно добавить сюда в том же PR, где он впервые переводится.

Перевод живёт в `apps/web/src/i18n/catalog/*.ts`: английский и русский текст стоят рядом (`defineMessages`).

## Стиль

- **К игроку — на «вы»**, без канцелярита. Пишем «Щёлкните по карте», а не «Осуществите клик».
- **Короткие подписи.** Подписи кнопок, вкладок и инструментов пишем со строчной буквы, как в оригинале («племя», «исцеление»). Если оригинал пишет с прописной (заголовки окон, названия настроек), тоже пишем с прописной.
- **Инструменты в доке называем существительными**, а не глаголами: «исцеление», «проклятие», «воскрешение». Подпись должна быть не длиннее 12–14 символов, иначе она не влезет в кнопку.
- **Подсказки инструментов пишем в повелительном наклонении на «вы»**: «Пошлите одного взрослого…», «Щёлкните по племени…». Смысл оригинала сохраняем полностью, порядок слов делаем русским.
- **Числа и плюралы:** только через `tn()` / `fmtNumber()`, без «человек(а)». Нужны формы `one` / `few` / `many` / `other`.
  - Форма `one` в русском — это и 1, и 21, и 101, поэтому в ней не пишем «одно», «последний» и не ставим местоимение «оно» там, где речь о многих. Особый текст ровно для одного («Одно племя просит…», «остался последний») — отдельный ключ, который код выбирает при `n === 1`.
  - Глагол после числа согласуем с ним в каждой форме: «21 племя молит», «3 племени молят». Не подставляем готовую глагольную фразу через `{placeholder}` в разные формы: все формы одного сообщения должны иметь одинаковый набор плейсхолдеров (это проверяет тест).
  - Дробные числа (возраст «1,5 года») берут форму «года»: для них отдельное сообщение без `tn()`.
- **Кавычки** «ёлочки». **Тире** — длинное (—) с пробелами. **Буква ё** пишется всегда.
- **Названия клавиш** (Esc, Shift, Ctrl, Space) не переводим. Space пишем как «Пробел».
- **Имена людей и племён** (латинские слоги из симуляции) не переводим и не склоняем через шаблон. Строим фразу так, чтобы имя стояло в именительном падеже: «Племя Lupif: …», а не «у Lupif’а».
- **Значения из симуляции, которые служат ключами** (id инструментов, `kind`, `era`, тексты мыслей), не трогаем. Переводим только то, что показываем.
